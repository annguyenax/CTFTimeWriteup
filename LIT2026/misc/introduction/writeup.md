# introduction

## Overview
A very simple miscellaneous challenge that gives us a file named `helloworld.txt`.

## Solution
1. Reading `helloworld.txt` reveals the string `YVGPGS{J3yp0z3_G0_Y1GPGS}`.
2. The format is similar to the flag format `LITCTF{...}`.
3. Applying a ROT13 shift to the string decodes it to `LITCTF{W3lc0m3_T0_L1TCTF}`.

**Flag:** `LITCTF{W3lc0m3_T0_L1TCTF}`
